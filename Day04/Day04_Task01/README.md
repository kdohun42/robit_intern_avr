# 1. Timer/Counter란?

Timer/Counter는 일정한 클럭이 입력될 때마다 내부 카운터 값을 증가시키는 장치이다.

Timer와 Counter의 의미는 다음과 같다.

1. Timer는 MCU 내부 클럭을 세어 일정한 시간을 측정하는 기능이다.
2. Counter는 외부 핀으로 들어오는 신호의 횟수를 측정하는 기능이다.

Timer/Counter를 사용하면 `_delay_ms()`처럼 CPU를 계속 대기시키지 않고도 일정한 시간마다 인터럽트를 발생시킬 수 있다.

또한 PWM 신호를 생성하여 LED 밝기나 모터 속도를 제어할 수 있다.

ATmega128의 Timer0과 Timer2는 모두 8비트 Timer/Counter이다.

8비트이므로 카운터 레지스터에는 0부터 255까지의 값이 저장된다.

Timer0과 Timer2는 다음 동작 모드를 지원한다.

1. Normal 모드
2. CTC 모드
3. Fast PWM 모드
4. Phase Correct PWM 모드

# 2. Timer/Counter의 동작 원리

Timer/Counter는 선택한 클럭이 입력될 때마다 `TCNTn` 레지스터의 값을 1씩 증가시킨다.

```text
0 → 1 → 2 → 3 → ... → 254 → 255 → 0
```

여기서 `n`은 타이머 번호를 의미한다.

Timer0에서는 `TCNT0`을 사용하고 Timer2에서는 `TCNT2`를 사용한다.

8비트 카운터가 255를 지나 다시 0으로 돌아가는 현상을 오버플로라고 한다.

오버플로가 발생하면 다음 플래그가 설정된다.

### Timer0

오버플로 플래그: `TOV0`

오버플로 인터럽트 허용 비트: `TOIE0`

### Timer2

오버플로 플래그: `TOV2`

오버플로 인터럽트 허용 비트: `TOIE2`

인터럽트를 활성화하면 오버플로가 발생했을 때 CPU가 자동으로 인터럽트 서비스 루틴을 실행한다.

Timer0과 Timer2는 오버플로뿐만 아니라 비교 일치 인터럽트도 지원한다.

# 3. 분주비의 의미

ATmega128이 16MHz로 동작하면 1초 동안 16,000,000개의 클럭이 발생한다.

이 클럭을 타이머에 그대로 사용하면 매우 짧은 시간 안에 카운터가 255에 도달한다.

따라서 Prescaler를 사용하여 CPU 클럭을 나눈 후 타이머에 공급한다.

### 타이머 클럭 계산

```text
타이머 클럭 = CPU 클럭 ÷ 분주비
```

16MHz CPU 클럭에서 분주비 64를 사용하면 다음과 같다.

```text
16,000,000 ÷ 64 = 250,000Hz
```

타이머에는 1초 동안 250,000개의 클럭이 입력된다.

한 번 카운트하는 데 걸리는 시간은 다음과 같다.

```text
1 ÷ 250,000 = 0.000004초
```

따라서 타이머 카운터는 4마이크로초마다 1씩 증가한다.

### Timer0의 분주비

Timer0은 다음 분주비를 사용할 수 있다.

1. 1
2. 8
3. 32
4. 64
5. 128
6. 256
7. 1024

### Timer2의 분주비

Timer2는 다음 분주비를 사용할 수 있다.

1. 1
2. 8
3. 64
4. 256
5. 1024

Timer2는 PD7의 T2 핀을 통해 외부 클럭을 입력받아 Counter로 사용할 수도 있다.

# 4. Timer0의 특징

Timer0은 범용 8비트 Timer/Counter이다.

Timer0은 다음 기능을 지원한다.

1. 0부터 255까지 카운트
2. 오버플로 인터럽트
3. 비교 일치 인터럽트
4. CTC 모드
5. Fast PWM 모드
6. Phase Correct PWM 모드
7. OC0 핀을 이용한 파형 출력
8. 외부 32.768kHz 크리스털을 이용한 비동기 동작

Timer0의 PWM 출력과 비교 출력은 PB4의 OC0 핀을 사용한다.

PWM 신호를 출력하려면 PB4를 출력으로 설정해야 한다.

## Timer0 비동기 동작

Timer0은 `ASSR` 레지스터의 `AS0` 비트를 설정하면 CPU의 메인 클럭과 독립적으로 동작할 수 있다.

이때 TOSC1과 TOSC2 핀에 32.768kHz 크리스털을 연결한다.

이 기능을 사용하면 ATmega128이 저전력 상태에서도 시간을 계속 측정할 수 있다.

따라서 시계나 RTC 기능을 구현할 때 사용할 수 있다.

32.768kHz 크리스털과 분주비 128을 사용하면 다음과 같다.

```text
32,768Hz ÷ 128 = 256Hz
```

8비트 타이머는 256번 카운트하면 오버플로가 발생한다.

```text
256 ÷ 256Hz = 1초
```

따라서 Timer0 오버플로 인터럽트를 1초마다 발생시킬 수 있다.

# 5. Timer2의 특징

Timer2도 범용 8비트 Timer/Counter이다.

Timer2는 다음 기능을 지원한다.

1. 0부터 255까지 카운트
2. 오버플로 인터럽트
3. 비교 일치 인터럽트
4. CTC 모드
5. Fast PWM 모드
6. Phase Correct PWM 모드
7. OC2 핀을 이용한 파형 출력
8. T2 핀을 이용한 외부 신호 계수

Timer2의 외부 카운터 입력은 PD7의 T2 핀을 사용한다.

센서나 스위치에서 펄스가 입력될 때마다 `TCNT2` 값을 증가시키는 방식으로 사용할 수 있다.

Timer2의 PWM 출력과 비교 출력은 PB7의 OC2 핀을 사용한다.

PB7은 Timer1의 OC1C 기능과 함께 사용되는 핀이므로 두 기능을 동시에 설정할 때 주의해야 한다.

# 6. 주요 레지스터

## TCCR0과 TCCR2

`TCCR0`과 `TCCR2`는 타이머의 동작 모드, 출력 방식, 클럭과 분주비를 설정하는 레지스터이다.

### TCCR0 구성

```text
FOC0 | WGM00 | COM01 | COM00 | WGM01 | CS02 | CS01 | CS00
```

### TCCR2 구성

```text
FOC2 | WGM20 | COM21 | COM20 | WGM21 | CS22 | CS21 | CS20
```

주요 비트의 기능은 다음과 같다.

1. `WGMn1`, `WGMn0`

   타이머의 동작 모드를 선택한다.

2. `COMn1`, `COMn0`

   비교 일치가 발생했을 때 OCn 핀의 출력 동작을 설정한다.

3. `CSn2`, `CSn1`, `CSn0`

   타이머의 클럭과 분주비를 선택한다.

4. `FOCn`

   PWM 모드가 아닐 때 강제로 비교 일치를 발생시킨다.

## TCNT0과 TCNT2

`TCNT0`과 `TCNT2`는 현재 타이머 카운트값을 저장하는 레지스터이다.

```text
저장 범위: 0부터 255
```

레지스터에 초기값을 직접 저장하면 오버플로가 발생하는 시간을 조절할 수 있다.

예를 들어 `TCNT0`에 200을 저장하면 200부터 카운트를 시작한다.

```text
200 → 201 → ... → 255 → 0
```

## OCR0과 OCR2

`OCR0`과 `OCR2`는 비교 기준값을 저장하는 레지스터이다.

타이머 카운트값과 OCR 값이 같아지면 비교 일치가 발생한다.

```text
TCNTn 값 == OCRn 값
           ↓
비교 일치 발생
           ↓
인터럽트 또는 출력 변화
```

## TIMSK

`TIMSK`는 Timer0과 Timer2의 인터럽트를 활성화하는 레지스터이다.

주요 비트는 다음과 같다.

1. `TOIE0`

   Timer0 오버플로 인터럽트를 활성화한다.

2. `OCIE0`

   Timer0 비교 일치 인터럽트를 활성화한다.

3. `TOIE2`

   Timer2 오버플로 인터럽트를 활성화한다.

4. `OCIE2`

   Timer2 비교 일치 인터럽트를 활성화한다.

## TIFR

`TIFR`은 오버플로와 비교 일치 발생 여부를 저장하는 플래그 레지스터이다.

주요 비트는 다음과 같다.

1. `TOV0`

   Timer0에서 오버플로가 발생하면 설정된다.

2. `OCF0`

   Timer0에서 비교 일치가 발생하면 설정된다.

3. `TOV2`

   Timer2에서 오버플로가 발생하면 설정된다.

4. `OCF2`

   Timer2에서 비교 일치가 발생하면 설정된다.

# 7. 동작 모드

## Normal 모드

Normal 모드에서는 카운터가 0부터 255까지 증가한다.

255를 넘어가면 다시 0으로 돌아가면서 오버플로가 발생한다.

```text
0 → 1 → 2 → ... → 255 → 0
```

Normal 모드는 일반적인 시간 측정이나 오버플로 인터럽트를 발생시킬 때 사용한다.

### 오버플로 시간 계산

```text
오버플로 시간
=
(256 - TCNT 초기값) × 분주비
÷ CPU 클럭
```

## CTC 모드

CTC는 Clear Timer on Compare Match의 약자이다.

CTC 모드에서는 `TCNTn` 값이 `OCRn` 값과 같아지면 카운터가 자동으로 0으로 초기화된다.

```text
0 → 1 → 2 → ... → OCRn → 0
```

CTC 모드는 1ms, 10ms와 같은 일정한 주기로 인터럽트를 발생시킬 때 사용한다.

### CTC 주기 계산

```text
CTC 주기
=
(OCRn + 1) × 분주비
÷ CPU 클럭
```

## Fast PWM 모드

Fast PWM 모드에서는 카운터가 0부터 255까지 증가한 후 다시 0으로 돌아간다.

```text
0 → 1 → 2 → ... → 255 → 0
```

`TCNTn`과 `OCRn`이 일치하는 위치를 이용하여 출력 신호의 듀티비를 변경한다.

### PWM 듀티비 계산

```text
PWM 듀티비
약 OCRn ÷ 255 × 100%
```

Fast PWM은 LED 밝기나 DC 모터 속도를 제어할 때 사용할 수 있다.

## Phase Correct PWM 모드

Phase Correct PWM 모드에서는 카운터가 0부터 255까지 증가한 후 다시 0까지 감소한다.

```text
0 → 1 → ... → 255 → 254 → ... → 0
```

Fast PWM보다 주파수는 낮지만 출력 파형이 대칭이라는 특징이 있다.

모터 제어처럼 대칭적인 PWM 파형이 필요한 경우 사용할 수 있다.

# 8. Timer0 CTC 모드 사용 예시

다음 코드는 Timer0을 이용하여 1ms마다 인터럽트를 발생시키는 코드이다.

```c
#define F_CPU 16000000UL

#include <avr/io.h>
#include <avr/interrupt.h>

void Timer0_Init(void)
{
	// Timer0 CTC 모드와 분주비 64 설정
	TCCR0 =
		(1 << WGM01) |
		(1 << CS02);

	// 1ms 주기 설정
	OCR0 = 249;

	// Timer0 비교 일치 인터럽트 활성화
	TIMSK |= (1 << OCIE0);

	// 전역 인터럽트 활성화
	sei();
}

ISR(TIMER0_COMP_vect)
{
	// 1ms마다 실행할 코드
}
```

주기는 다음과 같이 계산한다.

```text
(249 + 1) × 64
÷ 16,000,000
=
0.001초
=
1ms
```

Timer0에서 분주비 64를 사용하려면 `CS02` 비트를 1로 설정한다.

# 9. Timer2 CTC 모드 사용 예시

다음 코드는 Timer2를 이용하여 1ms마다 인터럽트를 발생시키는 코드이다.

```c
#define F_CPU 16000000UL

#include <avr/io.h>
#include <avr/interrupt.h>

void Timer2_Init(void)
{
	// Timer2 CTC 모드와 분주비 64 설정
	TCCR2 =
		(1 << WGM21) |
		(1 << CS21) |
		(1 << CS20);

	// 1ms 주기 설정
	OCR2 = 249;

	// Timer2 비교 일치 인터럽트 활성화
	TIMSK |= (1 << OCIE2);

	// 전역 인터럽트 활성화
	sei();
}

ISR(TIMER2_COMP_vect)
{
	// 1ms마다 실행할 코드
}
```

Timer0과 Timer2는 같은 1ms 주기를 만들 수 있지만 분주비 설정 비트가 다르다.

```
Timer0 분주비 64
CS02 = 1

Timer2 분주비 64
CS21 = 1
CS20 = 1
```

Timer0과 Timer2를 사용할 때는 각 타이머의 분주비 설정표를 구분하여 설정해야 한다.
