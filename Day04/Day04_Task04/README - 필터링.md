# 1. 개요

본 과제는 ATmega128과 PSD 거리 센서를 이용하여 거리를 측정하고, 센서값의 흔들림을 줄이기 위해 이동 평균 필터를 적용하는 것을 목표로 한다.

PSD 센서의 출력값은 주변광, 전원 노이즈, 물체 표면 상태와 센서 자체 오차로 인해 물체가 정지해 있어도 조금씩 변할 수 있다.

본 프로그램에서는 필터 적용 전 ADC 값을 `RAW`, 이동 평균 필터가 적용된 값을 `FILTERED`로 출력하여 필터 적용 전후의 변화를 비교하였다.

# 2. 이동 평균 필터의 개념

이동 평균 필터는 최근에 측정된 일정 개수의 값을 저장하고, 저장된 값들의 평균을 현재 출력값으로 사용하는 필터이다.

본 코드에서는 최근 10개의 ADC 값을 사용한다.

```c
#define FILTER_SIZE 10
```

### 필터값 계산

```text
필터값 = 최근 ADC 값 10개의 합 ÷ 10
```

새로운 ADC 값이 입력되면 가장 오래된 값은 제거되고, 새로운 값이 평균 계산에 포함된다.

이 과정을 반복하여 최근 측정값들의 평균을 계속 계산한다.

# 3. 이동 평균 필터의 구현

필터에 사용되는 주요 변수는 다음과 같다.

```c
uint16_t filter_buffer[FILTER_SIZE];
uint32_t filter_sum = 0;
uint8_t filter_index = 0;
uint8_t filter_count = 0;
```

### filter_buffer

최근에 측정된 ADC 값 10개를 저장하는 배열이다.

### filter_sum

현재 배열에 저장된 ADC 값들의 합을 저장한다.

### filter_index

새로운 ADC 값을 저장할 배열 위치를 나타낸다.

### filter_count

현재 배열에 저장된 유효한 ADC 값의 개수를 나타낸다.

### 필터 함수

```c
uint16_t MovingAverage_Filter(uint16_t raw_value)
{
	if (filter_count >= FILTER_SIZE)
	{
		filter_sum -= filter_buffer[filter_index];
	}
	else
	{
		filter_count++;
	}

	filter_buffer[filter_index] = raw_value;
	filter_sum += raw_value;

	filter_index++;

	if (filter_index >= FILTER_SIZE)
	{
		filter_index = 0;
	}

	return (uint16_t)((filter_sum + (filter_count / 2))
	/ filter_count);
}
```

필터 함수는 새로운 값이 입력되면 다음 순서로 동작한다.

1. 버퍼가 가득 찬 경우 가장 오래된 값을 합계에서 제거한다.
2. 새로운 ADC 값을 배열에 저장한다.
3. 새로운 ADC 값을 합계에 추가한다.
4. 저장 위치를 다음 칸으로 이동한다.
5. 현재 저장된 값들의 평균을 반환한다.

배열의 마지막 위치까지 사용하면 다시 첫 번째 위치로 돌아간다.

따라서 이 배열은 원형 버퍼 방식으로 동작한다.

RAW 값: 267

### 10번째 측정

RAW 값은 261부터 271까지 변하지만, FILTERED 값은 여러 측정값의 평균이므로 약 266 주변에서 안정적으로 유지된다.

### RAW 값의 변화 폭

```
RAW 변화 폭
= 271 - 261
= 10
```

### FILTERED 값의 변화 폭

```
FILTERED 변화 폭
= 268 - 265
= 3
```

필터를 적용하기 전에는 ADC 값의 변화 폭이 10이었지만, 필터를 적용한 후에는 변화 폭이 3으로 감소하였다.

따라서 이동 평균 필터가 ADC 값의 순간적인 변화와 노이즈를 줄이는 것을 확인할 수 있다.

# 5. 필터 적용 전후의 특징

## RAW 값의 특징

1. 센서에서 현재 측정한 원본값이다.
2. 센서의 변화에 빠르게 반응한다.
3. 노이즈의 영향을 크게 받는다.
4. 값의 흔들림이 크다.
5. 거리 출력값이 계속 변할 수 있다.

## FILTERED 값의 특징

1. 최근 측정값들의 평균이다.
2. RAW 값보다 변화 속도가 느리다.
3. 노이즈의 영향을 비교적 적게 받는다.
4. 값의 흔들림이 작다.
5. 거리 출력값을 안정적으로 유지할 수 있다.

이동 평균 필터를 적용하면 센서값의 흔들림은 감소한다.

하지만 여러 측정값을 평균 내기 때문에 물체가 빠르게 움직이면 실제 거리 변화보다 FILTERED 값이 늦게 반응할 수 있다.

# 6. 필터의 장단점

## 장점

1. 구현 방법이 단순하다.
2. 센서값의 노이즈와 흔들림을 줄일 수 있다.
3. 정수 연산만으로 구현할 수 있다.
4. 원형 버퍼를 사용하여 메모리를 반복해서 사용할 수 있다.
5. 누적 합계를 사용하므로 매번 배열 전체를 더할 필요가 없다.
6. 안정적인 거리값을 얻을 수 있다.

## 단점

1. 필터 크기가 커질수록 반응 속도가 느려진다.
2. 물체가 빠르게 움직일 때 변화가 늦게 반영될 수 있다.
3. 순간적으로 발생한 중요한 변화도 평균화될 수 있다.
4. 큰 이상값이 입력되면 일정 시간 동안 평균값에 영향을 줄 수 있다.

본 코드의 측정 주기는 약 100ms이고 필터 크기는 10이다.

```
100ms × 10개
= 1000ms
= 약 1초
```

따라서 필터가 가득 찬 이후에는 최근 약 1초 동안 측정한 ADC 값들이 평균 계산에 사용된다.

# 7. 동작 과정

1. PSD 센서의 ADC 원본값을 측정한다.
2. 측정값을 `RAW` 값으로 저장한다.
3. RAW 값을 이동 평균 필터 함수에 전달한다.
4. 최근 최대 10개의 ADC 값을 배열에 저장한다.
5. 저장된 ADC 값들의 평균을 계산한다.
6. 평균값을 `FILTERED` 값으로 저장한다.
7. FILTERED 값을 거리로 변환한다.
8. RAW 값과 FILTERED 값, 거리값을 UART로 출력한다.
9. 100ms마다 같은 과정을 반복한다.

거리 계산에는 RAW 값이 아닌 FILTERED 값을 사용한다.

따라서 필터를 적용하지 않았을 때보다 거리 표시값의 흔들림이 감소하고, 비교적 안정적인 거리값을 얻을 수 있다.
