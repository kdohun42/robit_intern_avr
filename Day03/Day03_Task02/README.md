## 1. 개요 (Overview)

본 과제는 ATmega128 마이크로컨트롤러의 USART0 통신, GPIO 출력 및 외부 인터럽트를 이용하여 컴퓨터에서 전송한 명령에 따라 LED를 제어하는 시스템을 구현하는 것을 목표로 함.

컴퓨터의 시리얼 터미널에서 숫자 `0`부터 `7`까지를 입력하면 해당 번호의 LED가 켜짐. 숫자 `8`을 입력하면 LED가 왼쪽 방향으로 순차 점등되고, 숫자 `9`를 입력하면 오른쪽 방향으로 순차 점등됨.

지정되지 않은 문자가 입력되면 오류 메시지를 출력하며, INT4 외부 인터럽트가 발생하면 USART0을 다시 초기화하고 시리얼 터미널에 `RESET` 메시지를 출력함.

### 핵심 목표

* USART0을 이용한 문자 데이터 송수신
* 컴퓨터에서 입력한 문자에 따른 LED 제어
* PORTA를 이용한 8개의 LED 출력
* 반복문을 이용한 좌우 방향 LED 순차 점등
* 조건문을 이용한 명령 구분
* 잘못된 입력에 대한 오류 처리
* INT4 외부 인터럽트를 이용한 초기화 메시지 출력

## 3. 하드웨어 구성 및 핀 맵 (Hardware Structure)

### Pin Configuration

```text
[ATmega128]                    [Target Component]

PA0 ~ PA7           -------->  8-Bit LED
PE0 / RXD0          <--------  USB to UART 모듈 TX
PE1 / TXD0          -------->  USB to UART 모듈 RX
PE4 / INT4          <--------  외부 인터럽트 스위치
GND                 -------->  LED, 스위치, UART 공통 GND
```

### 주요 회로 특징

* **전원:** ATmega128 개발보드에 5V DC 안정화 전원을 공급함.
* **LED 출력:** PORTA의 PA0부터 PA7까지 총 8개의 LED에 연결함.
* **LED 동작 방식:** 출력값이 LOW일 때 LED가 켜지는 Active Low 방식으로 동작함.
* **USART 통신:** USB to UART 모듈을 통해 컴퓨터의 시리얼 터미널과 데이터를 송수신함.
* **UART 연결:** ATmega128의 TXD0은 UART 모듈의 RX에 연결하고, RXD0은 UART 모듈의 TX에 연결함.
* **외부 인터럽트:** PE4의 INT4 핀에 스위치를 연결하여 인터럽트를 발생시킴.
* **공통 접지:** ATmega128, LED 모듈 및 USB to UART 모듈의 GND를 서로 연결함.
* **주의사항:** PE4에 내부 풀업 저항이 설정되어 있지 않으므로 회로에 외부 풀업 또는 풀다운 저항이 필요함.

## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### UART0 초기화

```c
void UART0_Init(unsigned int ubrr)
{
	UBRR0H = (unsigned char)(ubrr >> 8);
	UBRR0L = (unsigned char)ubrr;

	UCSR0B = (1 << RXEN0) | (1 << TXEN0);

	UCSR0C = (1 << UCSZ01) | (1 << UCSZ00);
}
```

USART0을 이용하여 컴퓨터와 문자 데이터를 송수신할 수 있도록 초기화함.

함수의 매개변수로 전달받은 `ubrr` 값을 `UBRR0H`와 `UBRR0L` 레지스터에 나누어 저장하여 통신 속도를 설정함.

```c
UART0_Init(103);
```

16MHz의 CPU 클럭에서 일반 비동기 통신 방식으로 9600bps를 사용하기 위한 UBRR 값은 다음과 같음.

```text
UBRR = 16,000,000 ÷ (16 × 9,600) - 1
     ≒ 103
```

USART0 통신 설정은 다음과 같음.

| 설정 항목  |   설정값   |
| :----- | :-----: |
| 통신 방식  |  비동기 통신 |
| 통신 속도  | 9600bps |
| 데이터 비트 |   8비트   |
| 패리티 비트 |    없음   |
| 정지 비트  |   1비트   |
| 송신 기능  |   활성화   |
| 수신 기능  |   활성화   |

`RXEN0` 비트를 설정하여 수신 기능을 활성화하고, `TXEN0` 비트를 설정하여 송신 기능을 활성화함.

`UCSZ01`과 `UCSZ00` 비트를 설정하여 데이터 길이를 8비트로 구성함.

### UART 문자 송신

```c
void UART0_Transmit(unsigned char data)
{
	while (!(UCSR0A & (1 << UDRE0)));

	UDR0 = data;
}
```

`UDRE0` 비트를 확인하여 USART0의 송신 버퍼가 비워질 때까지 기다림.

송신 버퍼가 비워지면 전송할 문자를 `UDR0` 레지스터에 저장함.

### UART 문자 수신

```c
unsigned char UART0_Receive(void)
{
	while (!(UCSR0A & (1 << RXC0)));

	return UDR0;
}
```

`RXC0` 비트가 1이 될 때까지 기다려 새로운 문자가 수신되었는지 확인함.

문자가 수신되면 `UDR0` 레지스터에 저장된 데이터를 반환함.

문자가 입력될 때까지 프로그램이 기다리는 블로킹 방식으로 동작함.

### UART 문자열 송신

```c
void UART0_Print(char *str)
{
	while (*str)
	{
		UART0_Transmit(*str++);
	}
}
```

문자열의 끝을 나타내는 널 문자 `'\0'`을 만날 때까지 문자열을 한 문자씩 USART0으로 전송함.

LED 동작 상태, 이동 방향, 오류 및 인터럽트 발생 메시지를 출력할 때 사용함.

### LED 출력 배열

```c
unsigned char led[8] =
{
	0b11111110,
	0b11111101,
	0b11111011,
	0b11110111,
	0b11101111,
	0b11011111,
	0b10111111,
	0b01111111
};
```

8개의 LED를 한 개씩 순서대로 켜기 위한 출력값을 배열에 저장함.

LED는 Active Low 방식으로 동작하므로 해당 비트가 `0`일 때 LED가 켜지고, `1`일 때 LED가 꺼짐.

|   배열 번호  |  PORTA 출력값 | 켜지는 LED |
| :------: | :--------: | :-----: |
| `led[0]` | `11111110` | PA0 LED |
| `led[1]` | `11111101` | PA1 LED |
| `led[2]` | `11111011` | PA2 LED |
| `led[3]` | `11110111` | PA3 LED |
| `led[4]` | `11101111` | PA4 LED |
| `led[5]` | `11011111` | PA5 LED |
| `led[6]` | `10111111` | PA6 LED |
| `led[7]` | `01111111` | PA7 LED |

### PORTA 초기화

```c
DDRA = 0b11111111;
PORTA = 0b11111111;
```

`DDRA`의 모든 비트를 1로 설정하여 PORTA의 PA0부터 PA7까지를 출력으로 설정함.

`PORTA`의 모든 비트를 1로 설정하여 프로그램 시작 시 모든 LED가 꺼진 상태가 되도록 함.

```text
PORTA = 11111111
         ↓
모든 LED 꺼짐
```

### 외부 인터럽트 초기화

```c
DDRE = 0b00000000;
EIMSK = 0b00010000;
EICRB = 0b00000010;
```

`DDRE`를 모두 0으로 설정하여 PORTE의 모든 핀을 입력으로 설정함.

`EIMSK`의 INT4 비트를 1로 설정하여 외부 인터럽트 4를 활성화함.

`EICRB`의 `ISC41`을 1, `ISC40`을 0으로 설정하여 INT4 핀에서 하강 에지가 발생할 때 인터럽트가 실행되도록 함.

```text
ISC41 ISC40 = 1 0
             ↓
하강 에지에서 INT4 발생
```

이후 `sei()` 함수를 호출하여 전역 인터럽트를 활성화함.

### 입력 문자 수신

```c
unsigned char rxData = UART0_Receive();
```

시리얼 터미널에서 입력된 문자 한 개를 수신하여 `rxData` 변수에 저장함.

수신된 문자는 조건문을 통해 `0`부터 `9`까지의 명령으로 구분함.

### 숫자 0~7 LED 개별 제어

```c
if (rxData == '0')
{
	UART0_Print("0Led on\r\n");
	PORTA = 0b11111110;
}
else if (rxData == '1')
{
	UART0_Print("1Led on\r\n");
	PORTA = 0b11111101;
}
```

문자 `'0'`부터 `'7'`까지 입력되면 입력된 번호에 해당하는 LED를 켬.

예를 들어 문자 `'0'`이 입력되면 PA0에 연결된 LED가 켜짐.

```text
입력 문자: '0'
PORTA: 11111110
결과: 0번 LED 켜짐
```

문자 `'5'`가 입력되면 다음과 같이 동작함.

```text
입력 문자: '5'
PORTA: 11011111
결과: 5번 LED 켜짐
```

각 명령이 실행되면 시리얼 터미널에 어떤 LED가 켜졌는지 출력함.

### 왼쪽 방향 순차 점등

```c
else if (rxData == '8')
{
	UART0_Print("LEFT\r\n");

	for (int i = 0; i < 8; i++)
	{
		_delay_ms(200);
		PORTA = led[i];
	}
}
```

문자 `'8'`이 입력되면 배열의 0번 요소부터 7번 요소까지 순서대로 출력함.

```text
PA0 → PA1 → PA2 → PA3 → PA4 → PA5 → PA6 → PA7
```

각 LED가 변경되기 전에 200ms 동안 대기하므로 LED가 한 칸씩 이동하는 것처럼 보임.

시리얼 터미널에는 다음 문구가 출력됨.

```text
LEFT
```

### 오른쪽 방향 순차 점등

```c
else if (rxData == '9')
{
	UART0_Print("RIGHT\r\n");

	for (int i = 7; i >= 0; i--)
	{
		_delay_ms(200);
		PORTA = led[i];
	}
}
```

문자 `'9'`가 입력되면 배열의 7번 요소부터 0번 요소까지 역순으로 출력함.

```text
PA7 → PA6 → PA5 → PA4 → PA3 → PA2 → PA1 → PA0
```

각 LED는 200ms 간격으로 변경되며 시리얼 터미널에는 다음 문구가 출력됨.

```text
RIGHT
```

### 잘못된 입력 처리

```c
else
{
	UART0_Print("ERROR\r\n");
}
```

문자 `'0'`부터 `'9'` 이외의 데이터가 입력되면 지정되지 않은 명령으로 판단함.

LED 상태는 변경하지 않고 시리얼 터미널에 다음 오류 메시지를 출력함.

```text
ERROR
```

### INT4 외부 인터럽트

```c
ISR(INT4_vect)
{
	UART0_Print("RESET\r\n");
	UART0_Init(103);
}
```

PE4의 INT4 핀에서 하강 에지가 발생하면 해당 인터럽트 서비스 루틴이 실행됨.

인터럽트가 발생하면 시리얼 터미널에 `RESET` 문자열을 출력하고 USART0을 9600bps로 다시 초기화함.

현재 코드는 ATmega128 전체를 초기화하는 실제 리셋이 아니라, 메시지를 출력하고 UART 설정을 다시 수행하는 동작임.

LED를 초기 상태로 되돌리려면 인터럽트 함수에 다음 코드를 추가해야 함.

```c
PORTA = 0b11111111;
```

## 6. 동작 설명 및 결과 (Results)

### 동작 시나리오

1. 프로그램이 시작되면 PORTA의 모든 핀을 출력으로 설정함.
2. PORTA에 `11111111`을 출력하여 모든 LED를 끔.
3. PORTE를 입력으로 설정함.
4. INT4 외부 인터럽트를 하강 에지 방식으로 설정함.
5. 전역 인터럽트를 활성화함.
6. USART0을 9600bps, 데이터 8비트, 패리티 없음, 정지 비트 1개로 초기화함.
7. 컴퓨터의 시리얼 터미널에서 문자 입력을 기다림.
8. 문자 `0`부터 `7`까지 중 하나가 입력되면 해당 번호의 LED를 켬.
9. 문자 `8`이 입력되면 LED가 PA0에서 PA7 방향으로 순차 점등됨.
10. 문자 `9`가 입력되면 LED가 PA7에서 PA0 방향으로 순차 점등됨.
11. 지정되지 않은 문자가 입력되면 `ERROR` 메시지를 출력함.
12. INT4 스위치가 눌려 하강 에지가 발생하면 `RESET` 메시지를 출력함.
13. INT4 인터럽트에서 USART0을 다시 초기화함.
14. 이후 새로운 UART 명령을 계속 입력받아 LED를 제어함.
